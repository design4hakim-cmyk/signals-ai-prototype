1 · FoundationsTwo layers: the component’s own look, and the editor layer on top
Blue · editorHover, pressed, selected, focus, drop target. Only in the editor layer.
Grey · structureDefault surfaces and edges. Menu row hover.
Violet · CopilotAdded or changed by Copilot. Never hover or focus.
Red · errorInvalid conditions and destructive actions. With an icon and message.
Green · successA check passed or a save worked.
Yellow · favouriteThe ★ on indicators.
Editor interaction tokensDrawn outside the element’s border (rings and outlines). Built only from the existing blue (#0782DA) and soft blue (#9cc8ee).
EDITOR STATETREATMENTEXAMPLERULE
DefaultnothingThe component’s own look, untouched.
Hover1px #9cc8ee ring outside the elementTemporary. Interactive canvas elements only, never static text or disabled.
Pressed1px #0782DA ringOnly while the pointer is down. Stronger than hover, never mistaken for selected.
Selected2px #0782DA ringPersists after the pointer leaves. Strongest. Contextual controls show.
Focused2px gap + 2px #0782DA ringKeyboard focus only. Sits outside any other ring.
Selected + focusedboth rings, focus outermostBoth visible; neither replaces the other.
Drop target1.5px dashed #0782DA outline, 3px outWhere a dragged item will land. Dashed, so never read as selected.
Invalid drop1.5px dashed #b42318 outline, 3px outWith the reason in words.
Draggingselected ring + lift shadow + slight tiltThe source stays behind, faded and dashed grey.
PrecedenceWhen states meet.
  • Disabled overrides hover, pressed and selected: no editor layer at all.
  • Semantic styling always shows: red error, violet Copilot, dashed empty and grey edges stay under every editor ring.
  • Selected beats pressed beats hover (only one inner ring). Focus is added outside it, independently.
  • Hover is temporary and marks only the innermost element under the pointer.
  • Selection persists and belongs to one element: it never spreads to children or parents.
  • Drop target (dashed) and selected (solid) never look the same; the dragged copy and its source never look the same.
  • Copilot provenance (✦ + violet) stays visible whatever the editor state.

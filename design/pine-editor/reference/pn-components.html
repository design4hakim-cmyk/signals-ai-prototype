0 · How it stays in syncThe draft is what you type; canvas, chart and backtest only show the last code that ran
Model
CanvasBlocks you build by hand
Every change patches its lines in. Silent: no message, no highlight.→
Pine ScriptOne script per strategy. The source the chart and backtest run.
Run: if it compiles, the canvas redraws and the chart refreshes.←
Your code editsTyped in the editor. Nothing moves until Run.
Copilot changes canvas and code together. Its lines and blocks are violet until you edit them.
Chart reads the last code that ran. It pauses on any change; Run and Update chart both refresh it.
Rules
WHENWHAT HAPPENS
Where it livesThe Pine Script view inside the Copilot panel, as today: the toggle in the Copilot header switches the panel between Chat and code. The canvas stays on the left, so code and blocks sit side by side. The panel can be dragged from 440 to 640px while in code.
You build on the canvasThe matching lines are patched into the script right away, silently: no bar, no toast, no highlight. Only that block’s lines change; your names, comments and spacing stay. The caret and scroll never move.
You type in the editorOnly the draft changes. The status line says “3 lines changed · not run”, edited lines get a thin blue gutter bar, Discard and Run turn on. Canvas and chart wait. A live check runs 600ms after you stop typing: squiggles only, no cards.
You press Run (⌘↵, or ⌘S in the editor)Compiles the whole draft. No errors → the canvas redraws, changed blocks glow once (1s), the chart refreshes, the status line says “In sync”. No toast. Errors → nothing commits; the first error opens its AI fix card.
Code the canvas can’t drawDecided at Run, line by line. A line with no block becomes one grey Custom logic block (“Open line 7”). If the structure can’t be drawn (memory between candles), the canvas shows one Runs from Pine Script card instead.
Copilot changes thingsFrom the Ask box under the editor: a text edit in the draft, then it runs (⌘Z takes it back). From the Chat view: patched in silently, with Undo in its chat card. Either way Copilot’s lines get violet gutter marks until you edit them. No bar in the editor.
Discard changesThrows away only what hasn’t run: the draft goes back to the last run. Off when there is nothing un-run. No confirm, no toast: ⌘Z brings the text back. It never touches the canvas, Copilot changes or the chart.
UndoThree ways back, each where the change was made: ⌘Z in the editor (your typing, AI fixes, Ask-box changes, Discard), ⌘Z on the canvas (blocks), Undo in a Copilot chat card. There is no strategy version history; the clock icon is Copilot chat history.
You close the editor (switch to Chat)Code that ran stays. A draft that hasn’t run is kept; the Pine Script toggle shows a blue dot and the status line says “Draft from 16:10 · not run” when you come back.

FIX 1Status icons are black
  • Done, Failed and Needs-you icons render black.
  • Cause: the class name is built at runtime (map.bg.replace('bg-', 'fill-')), so Tailwind never generates fill-success / fill-error.
Rule. Write full class names literally in a lookup: { done: 'fill-success', failed: 'fill-error', needs: 'fill-warn-dot' }. Done = green, Failed = red, Needs you = amber.

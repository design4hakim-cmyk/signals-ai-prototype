Decisions
DECISIONWHY
DatesRemoved (created and last updated)They don’t help pick a strategy. Recency already shows in the order: last edited first.
“Draft” chipRemovedEverything in this panel is saved. Unsaved work is shown in the top nav, not here.
Running statusCounts: “2 Live”, “1 FT” (forward test; full words on hover). Shown only when something runs.One strategy can run several setups at once. Counts say how many. Chips are information, never buttons.
TradeOutlined blue button on row hover / focus. Also in ⋯.Starts a new live or forward test, including one more for a strategy that already runs. Outlined so it never competes with the page’s one filled-blue action.
⋯ menuOpen in builder · Trade… · Rename · Duplicate · DeleteKeeps the row clean; every action has a keyboard shortcut.
RenameInline, in the row. ⋯ → Rename, F2 or double-click the name.No dialog for a one-field change. Enter saves, Esc cancels. Empty or duplicate names (within the same index) are refused.
DeleteConfirm popover. Blocked while anything is running.It removes saved setups and results too, so it gets one confirm. A strategy with live or forward tests must be stopped first, so trades are never orphaned.
Long namesWrap to 2 lines, then “…” with the full name on hoverNames are how people tell strategies apart; one line cut them too often at 290px.
Index rows (collapsed)Same content: avatar, symbol, strategy count, chevronRows are now rounded and sit inside the panel, so hover, pressed and focus fills follow the corners instead of running square into them.
Expanded indexA soft tinted card holding the index and its strategies; the index name turns boldGroups the strategies with their index. No connecting lines or dots: strategies are independent, and lines would read as a sequence or a process.
Index iconThe instrument’s own logo when the data has one; the letter tile as fallbackReal logos are recognised faster than letters. They come from the instrument data (AlgoTest’s icon set), never drawn by hand.
